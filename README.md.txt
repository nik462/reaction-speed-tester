# Reaction Speed Tester

A simple open-source web app that measures human reaction time.  
When the box turns green, the user must click as fast as possible.

## Features
- Random delay before activation
- Measures reaction time in milliseconds
- Clean and minimal UI
- 100% open-source and beginner-friendly

## Why I built this
I wanted to create a small but useful tool that helps people test their reflexes.  
It can be used for fun, training, or even simple experiments.

## How to use
1. Open index.html in any browser  
2. Wait for the box to turn green  
3. Click as fast as possible  
4. Your reaction time will be displayed
